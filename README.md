## Лабораторная работа 3: Коллекции и компараторы в Java

### Цель работы:
- Освоить работу с коллекциями в Java
- Изучить интерфейсы Comparable и Comparator
- Научиться работать с различными типами Set и Map коллекций

### Выполненные задания:

#### Задание 1: Работа с Collections (1 балл)
- Создание и манипуляция списками с помощью методов класса Collections
- Сортировка, перемешивание, поиск дубликатов
- Подсчет частоты вхождений элементов

#### Задание 2: Генератор простых чисел (2 балла)
- Реализация генератора простых чисел с использованием Iterator
- Вывод чисел в прямом и обратном порядке

#### Задание 3: Класс Human и компараторы (3 балла)
- Создание класса Human с реализацией Comparable
- Различные компараторы для сортировки
- Демонстрация различий между HashSet, LinkedHashSet и TreeSet

#### Задание 4: Подсчет частоты слов (2 балла)
- Анализ текста и подсчет частоты слов с использованием HashMap

#### Задание 5: Обращение Map (3 балла)

- Обработка дублирующихся значений
